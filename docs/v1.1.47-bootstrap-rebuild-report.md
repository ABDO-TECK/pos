## 2. Production Fixes Included in Rebuild

1. **Database Migration Pipeline Stabilization**:
   - Fixed SQL syntax and semicolon parsing in migrations `052_extend_update_history_table.sql` and `054_add_update_channel_and_rollout.sql`.
   - Corrected index definitions on `products` table in `057_add_product_search_indexes.sql` to match canonical schema (`idx_products_barcode_deleted` on `barcode, deleted_at`).
2. **Health Check Canonical Table Correction**:
   - Replaced legacy `sales` check in `HealthService.php` and `UpdateRecoveryService.php` with the canonical production `invoices` table, eliminating false positive alerts.
3. **Customer-Facing Electron Update Flow**:
   - Integrated [`electron/update/CustomerUpdateManager.js`](file:///c:/xampp/htdocs/pos/electron/update/CustomerUpdateManager.js) with chunked download tracking and detached NSIS execution.
   - Integrated [`electron/update/SafeShutdown.js`](file:///c:/xampp/htdocs/pos/electron/update/SafeShutdown.js) for graceful database flushing, shutdown markers, and file lock prevention.
   - Added friendly Arabic UI components: `UpdateNotification.tsx` and `UpdateProgress.tsx`.
4. **Backend Customer Endpoints & Telemetry**:
   - Added `GET /api/updates/customer-status` and `POST /api/updates/customer-result`.
   - Extended `UpdateTelemetryService::ALLOWED_EVENTS` with `update_ui_opened`, `installer_started`, `installer_completed`, and `installer_failed`.
